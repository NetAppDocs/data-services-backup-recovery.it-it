= Esegui il backup dei carichi di lavoro di Oracle Database utilizzando NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Esegui il backup dei gruppi di protezione di database Oracle o di singoli database dai sistemi ONTAP on-premises utilizzando NetApp Backup and Recovery. Invia i backup al cloud storage, inclusi Amazon S3, NetApp StorageGRID, Microsoft Azure Blob Storage o ONTAP S3.


NOTE: Per eseguire il backup di gruppi di protezione o singoli database in base a una pianificazione, creare policy che gestiscano le operazioni di backup e ripristino. Vederelink:br-use-policies-create.html["Creare politiche"] per istruzioni.

* Crea gruppi di protezione per gestire le operazioni di backup e ripristino per un insieme di risorse. Vedi link:br-use-kvm-protection-groups.html["Crea e gestisci gruppi di protezione per i carichi di lavoro di Oracle Database con NetApp Backup and Recovery"] per maggiori informazioni.
* Crea un backup su richiesta di un gruppo di protezione.
* Crea un backup su richiesta di un database.




[[create-an-on-demand-backup-of-a-protection-group]]
== Crea un backup su richiesta di un gruppo di protezione

Crea un backup su richiesta prima di apportare modifiche al sistema per proteggere i tuoi dati.

*Ruolo richiesto NetApp Console* Super amministratore di Backup and Recovery o ruolo di amministratore di backup di Backup and Recovery. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Scopri di più sui ruoli di accesso NetApp Console per tutti i servizi"^].

.Passi
. Dal menu NetApp Console , selezionare *Protezione > Backup e ripristino*.
. In *Carichi di lavoro*, seleziona il riquadro *Oracle*.
. Selezionare *Inventario*.
. Selezionare un carico di lavoro per visualizzare i dettagli della protezione.
. Seleziona l'icona Azioniimage:../media/icon-action.png["Opzione Azioni"] > *Visualizza dettagli*.
. Seleziona la scheda *Gruppi di protezione*.
. Selezionare il gruppo di protezione di cui si desidera eseguire il backup.
. Seleziona l'icona Azioniimage:../media/icon-action.png["Opzione Azioni"] > *Esegui il backup ora*.
+

NOTE: NetApp Backup and Recovery utilizza la stessa policy sia per il gruppo di backup che per quello di protezione.

. Selezionare il livello di pianificazione.
. Selezionare *Backup*.
