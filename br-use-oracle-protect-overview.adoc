= Proteggi i carichi di lavoro del database Oracle con NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Usa NetApp Backup and Recovery per proteggere i carichi di lavoro e i log di database Oracle con backup e ripristini rapidi, efficienti in termini di spazio, coerenti con il crash e coerenti con il database. Puoi eseguire il backup dei carichi di lavoro su Amazon S3, StorageGRID, Azure Blob o ONTAP S3 e ripristinare i backup su un host Oracle on-premises.

Utilizza NetApp Backup and Recovery per implementare una strategia di protezione 3-2-1, in cui hai tre copie dei dati di origine su due diversi sistemi di storage insieme a una copia nel cloud. I vantaggi dell'approccio 3-2-1 includono:

* Più copie di dati proteggono dalle minacce informatiche interne ed esterne.
* Diversi tipi di supporti ti aiutano a eseguire il ripristino se uno di essi si guasta.
* È possibile ripristinare rapidamente dalla copia in loco e utilizzare le copie fuori sede se la copia in loco è compromessa.




[[oracle-data-guard-support]]
== Supporto per Oracle Data Guard

NetApp Backup and Recovery può proteggere le configurazioni Oracle Data Guard che dispongono di un database primario a istanza singola e di un database standby fisico nello stato montato.
