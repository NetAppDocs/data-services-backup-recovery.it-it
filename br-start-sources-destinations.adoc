Esamina i sistemi di origine, i sistemi secondari e le destinazioni di storage a oggetti che NetApp Backup and Recovery supporta per le operazioni di backup e ripristino tra i carichi di lavoro.



[[supported-systems-for-backup-and-restore-operations]]
== Sistemi supportati per operazioni di backup e ripristino

NetApp Backup and Recovery supporta i sistemi ONTAP e i provider di cloud pubblici e privati.



[[supported-regions]]
=== Regioni supportate

NetApp Backup and Recovery è supportato con Cloud Volumes ONTAP in molte regioni di Amazon Web Services, Microsoft Azure e Google Cloud.

https://bluexp.netapp.com/cloud-volumes-global-regions["Scopri di più utilizzando la mappa delle regioni globali"^]

[[supported-restore-destinations]]
=== Destinazioni di ripristino supportate

È possibile ripristinare i dati da un file di backup, una macchina virtuale, un database o una risorsa Kubernetes che risiede in un sistema secondario (un volume replicato) o nello storage a oggetti (un file di backup) nei seguenti sistemi. Gli Snapshot risiedono nel sistema di origine e possono essere ripristinati solo in quello stesso sistema.


NOTE: Wasabi è l'unico provider di storage a oggetti compatibile con S3 qualificato al momento. Gli altri provider compatibili con S3 non sono stati convalidati.

Tieni presenti le seguenti considerazioni relative al ripristino:

* I ripristini da Cloud Volumes ONTAP (replicazione) possono essere effettuati solo su Cloud Volumes ONTAP. Tuttavia, Cloud Volumes ONTAP in AWS supporta anche il ripristino su Amazon FSx for NetApp ONTAP.
* I ripristini da ONTAP on-premise (replica) possono essere eseguiti solo su ONTAP on-premise.
* I ripristini da Amazon FSx for NetApp ONTAP e Google Cloud NetApp Volumes (replica) possono essere eseguiti solo nel rispettivo sistema proprietario.
* Il ripristino da Amazon S3 ad Amazon FSx for NetApp ONTAP deve seguire questo ordine: Amazon S3 a Cloud Volumes ONTAP e poi Cloud Volumes ONTAP ad Amazon FSx for NetApp ONTAP.



NOTE: I riferimenti a "on-premises ONTAP system" includono i sistemi FAS, AFF e ONTAP Select.
