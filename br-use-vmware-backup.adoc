= Esegui il backup dei carichi di lavoro VMware con NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Esegui il backup di macchine virtuali VMware e datastore dai sistemi ONTAP locali su Amazon Web Services, Azure NetApp Files o StorageGRID per aiutarti a proteggere i tuoi dati. I backup vengono generati automaticamente e archiviati in un archivio di oggetti nel tuo account cloud pubblico o privato.

* Per eseguire il backup dei carichi di lavoro in base a una pianificazione, crea policy che regolano le operazioni di backup e ripristino. Vedere link:br-use-policies-create.html["Creare policy di protezione"] per le istruzioni.
* Crea gruppi di protezione per gestire le operazioni di backup e ripristino per un set di risorse. Vedere link:br-use-vmware-protection-groups.html["Creare e gestire gruppi di protezione"] per ulteriori informazioni.
* Esegui subito il backup dei workload creando un backup su richiesta.




[[back-up-workloads-now-with-an-on-demand-backup]]
== Esegui subito il backup dei carichi di lavoro con un backup on-demand

Crea subito un backup su richiesta.  Se stai per apportare modifiche al tuo sistema e vuoi assicurarti di avere un backup prima di iniziare, potresti voler eseguire un backup su richiesta.

*Ruolo della NetApp Console richiesto* Visualizzatore di storage, super admin di Backup and Recovery, backup admin di Backup and Recovery, restore admin di Backup and Recovery, clone admin di Backup and Recovery o ruolo di viewer di Backup and Recovery. Se stai proteggendo dati archiviati su un cluster Cloud Volumes ONTAP, è richiesto anche il ruolo Cloud Volumes ONTAP Admin. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Scopri di più sui ruoli di accesso NetApp Console per tutti i servizi"^].

.Passi
. Dal menu NetApp Backup and Recovery , selezionare *Inventario*.
. Seleziona il carico di lavoro VMware.
. Seleziona l'icona Azioniimage:../media/icon-action.png["Opzione Azioni"] > *Visualizza dettagli*.
. Seleziona la voce di menu *Gruppi di protezione*, *Archivi dati*, *Macchine virtuali* o *Tag*.
. Seleziona il gruppo di protezione, i datastore, le macchine virtuali o le risorse con tag di cui desideri eseguire il backup.
. Seleziona l'icona Azioniimage:../media/icon-action.png["Opzione Azioni"] > *Esegui il backup ora*.
+

NOTE: La policy applicata al backup è la stessa policy assegnata al gruppo di protezione, al datastore, alla macchina virtuale o alle risorse con tag.

. Selezionare il livello di pianificazione.
. Seleziona *Esegui backup ora*.




[[delete-backups]]
== Elimina i backup

Puoi eliminare i backup locali non più necessari per liberare spazio di storage o soddisfare i requisiti di conservazione dei dati.

.Passi
. Accedi a NetApp Backup and Recovery e, dalla schermata iniziale, seleziona il riquadro del carico di lavoro VMware.
+
Viene visualizzata la pagina Inventario VMware.

. Seleziona la voce *Macchine virtuali*.
. Nell'elenco delle macchine virtuali, scegli una macchina virtuale e seleziona l'icona Azioni image:../media/icon-action.png["Opzione Azioni"] > *Visualizza dettagli di protezione*.
. Seleziona un intervallo di tempo per visualizzare le istantanee pertinenti.
. Elimina una o più istantanee:
+
[role="tabbed-block"]
====
.Elimina una singola istantanea
--
.. Scegli un'istantanea dall'elenco che vuoi eliminare e seleziona l'icona Azioni image:../media/icon-action.png["Opzione Azioni"] > *Elimina istantanea locale*.


--
.Elimina più snapshot
--
.. Seleziona la check box a sinistra di ogni snapshot che vuoi eliminare.
.. Seleziona *Elimina selezionato*.


--
