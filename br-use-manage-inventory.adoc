= Gestisci l'inventario di Microsoft SQL Server con NetApp Backup and Recovery
:hardbreaks:
:allow-uri-read: 
:nofooter:

:linkattrs:

[role="lead"]
Visualizza e gestisci host, istanze e database di Microsoft SQL Server, e modifica o rimuovi le relative impostazioni di protezione.

Puoi fare quanto segue per gestire il tuo inventario:

* Gestisci le informazioni dell'host
+
** Sospendere gli orari
** Modifica o elimina gli host


* Gestisci le informazioni dell'istanza
+
** Associare le credenziali a una risorsa
** Esegui subito il backup avviando un backup su richiesta
** Modifica le impostazioni di protezione


* Gestire le informazioni del database
+
** Proteggere i database
** Ripristinare i database
** Modifica le impostazioni di protezione
** Esegui subito il backup avviando un backup su richiesta


* Configura la directory dei log da *Inventory* > *Hosts* prima di eseguire il backup dei log degli host del database negli snapshot. Per i dettagli, vedi link:br-start-setup.html["Configurare le impostazioni NetApp Backup and Recovery"].




[[manage-host-information]]
== Gestisci le informazioni dell'host

Gestisci le informazioni sugli host per garantire che gli host corretti siano protetti. Visualizza, modifica ed elimina le informazioni sugli host secondo necessità.

*Ruolo richiesto nella NetApp Console* Storage viewer, Backup and Recovery super admin, Backup and Recovery backup admin, Backup and Recovery restore admin o Backup and Recovery clone admin. Se stai proteggendo dati archiviati su un cluster Cloud Volumes ONTAP, è richiesto anche il ruolo Cloud Volumes ONTAP Admin. https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Scopri di più sui ruoli di accesso NetApp Console per tutti i servizi"^].

* Configura la directory dei log. Per i dettagli, vedi link:br-start-setup.html["Configurare le impostazioni NetApp Backup and Recovery"].
* Sospendere gli orari
* Modifica un host
* Elimina un host




[[manage-hosts]]
=== Gestisci gli host

Puoi gestire gli host rilevati nel tuo sistema, singolarmente o come gruppo.


TIP: Per gestire un host, cerca lo stato "Non gestito" nella colonna Host. NetApp Backup e ripristino gestisce già gli host con stato "Gestito".

Dopo aver gestito gli host in NetApp Backup and Recovery, SnapCenter non gestisce più le risorse su tali host.

*Ruolo richiesto nella NetApp Console* Visualizzatore di archiviazione o super amministratore di backup e ripristino. Se stai proteggendo dati archiviati su un cluster Cloud Volumes ONTAP, è richiesto anche il ruolo di Cloud Volumes ONTAP Admin https://docs.netapp.com/us-en/console-setup-admin/reference-iam-predefined-roles.html["Scopri di più sui ruoli di accesso NetApp Console per tutti i servizi"^].

.Passi
. Dal menu, seleziona *Inventario*.
. Selezionare un carico di lavoro per visualizzare i dettagli della protezione.
. Seleziona l'icona Azioniimage:../media/icon-action.png["Opzione Azioni"] > *Visualizza dettagli*.
. Selezionare la scheda *Host*.
. Seleziona uno o più host. Se selezioni più host, viene visualizzata l'opzione *Bulk actions*. Seleziona *Manage (up to 5 hosts)*.
. Seleziona l'icona Azioniimage:../media/icon-action.png["Opzione Azioni"] > *Gestisci*.
. Esaminare le dipendenze dell'host:
+
** Se vCenter non viene visualizzato, selezionare l'icona della matita per aggiungere o modificare i dettagli di vCenter.
** Se si aggiunge un vCenter, è necessario anche registrarlo selezionando *Registra vCenter*.


. Seleziona *Convalida impostazioni* per testare le tue impostazioni.
. Selezionare *Gestisci* per gestire l'host.




[[suspend-schedules]]
=== Sospendere gli orari

Sospendi le pianificazioni per interrompere le operazioni di backup e ripristino durante la manutenzione dell'host.

.Passi
. Dal menu NetApp Backup and Recovery , selezionare *Inventario*.
. Seleziona l'host su cui vuoi sospendere le pianificazioni.
. Seleziona *Azioni*image:icon-action.png["Icona Azioni"] icona e seleziona *Sospendi pianificazioni*.
. Nella finestra di dialogo di conferma, seleziona *Sospendi*.

[[protect-database-instances]]
=== Proteggere le istanze del database

Assegna una policy a un'istanza di database per gestire la pianificazione e la conservazione della protezione delle risorse.

.Passi
. Dal menu NetApp Backup and Recovery , selezionare *Inventario*.
. Seleziona il carico di lavoro che desideri visualizzare e seleziona *Visualizza*.
. Selezionare la scheda *Istanze*.
. Selezionare l'istanza.
. Seleziona *Azioni*image:icon-action.png["Icona Azioni"] icona e seleziona *Proteggi*.
. Seleziona una policy o creane una nuova.
+
Per dettagli sulla creazione di una policy, vedi link:br-use-policies-create.html["Crea una politica"].

. Fornisci gli script da eseguire prima e dopo il backup.
+
** *Pre-script*: Inserisci il nome e il percorso del file dello script da eseguire automaticamente prima che inizi l'azione di protezione. Usa questa opzione per svolgere attività o configurazioni aggiuntive prima del workflow di protezione.
** *Post-script*: Inserisci il nome e il percorso del file dello script da eseguire automaticamente al termine dell'azione di protezione. Usa questa opzione per eseguire attività o configurazioni aggiuntive dopo il workflow di protezione.


. Fornisci le informazioni di verifica per la snapshot:
+
** Posizione di archiviazione: Seleziona dove archiviare la snapshot di verifica.
** Risorsa di verifica: Seleziona se verificare la risorsa sullo snapshot locale, sullo storage secondario ONTAP o su entrambi.
** Programma di verifica: Seleziona la frequenza: oraria, giornaliera, settimanale, mensile o annuale.
