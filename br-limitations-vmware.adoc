= Limitazioni note per i carichi di lavoro VMware in NetApp Backup e ripristino
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Esamina queste limitazioni prima di utilizzare NetApp Backup e ripristino per i carichi di lavoro VMware.

NetApp Backup e ripristino non supporta le seguenti azioni per i carichi di lavoro VMware:

* Nella versione di anteprima di Backup and Recovery per la distribuzione locale di NetApp Console, i backup su storage a oggetti sono supportati solo per le destinazioni ONTAP S3 e StorageGRID. L'archiviazione dei backup non è supportata in questa versione di anteprima.
* Supporto vVol
* Integrazione e-mail
* Supporto per il controllo degli accessi basato sui ruoli (RBAC)
